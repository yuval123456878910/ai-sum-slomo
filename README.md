# Stress Radar

A research bot plus a website. It scans Israeli industrial companies for financial and operational stress in five sectors: plastics, food, packaging, chemicals and metal. It also scores how likely each case is to become a real-estate or business deal. Scans run at **07:00 and 19:00 Israel time**, and you can also start one with the **Run scan now** button.

- **Research**: OpenRouter chat model + OpenRouter web-search plugin. Each sector is its own call. A company gets one primary sector. Repeat findings are marked as *update* (not *new*) and keep their sector across runs.
- **Hosting**: Render free web service.
- **Storage**: `db.json` on the `data` branch of this GitHub repo. Free Render instances lose their disk when they sleep, so the data can't stay there.
- **Schedule**: GitHub Actions (`.github/workflows/scan.yml`) wakes the site at both possible UTC hours and calls `/api/cron`. The site runs each 07:00 / 19:00 slot once. While a scan runs, the site pings itself so it stays awake.
- **Login**: HTTP basic auth (`ADMIN_USER` / `ADMIN_PASSWORD`).

## Setup

1. **GitHub token** for storage: GitHub → Settings → Developer settings → Fine-grained tokens → Generate.
   Choose *Only select repositories* → this repo. Under Permissions → Repository → **Contents: Read and write**.
2. **Render**: create the service from this Blueprint. Then, under the service's **Environment**, set:
   - `OPENROUTER_API_KEY`: from https://openrouter.ai/keys
   - `ADMIN_PASSWORD`: the site password
   - `GITHUB_TOKEN`: the token from step 1
   - `CRON_SECRET` is generated by Render. Copy its value for step 3.
3. **GitHub Actions secrets**: repo → Settings → Secrets and variables → Actions → *New repository secret*:
   - `SITE_URL`: the Render URL, e.g. `https://stress-radar.onrender.com`
   - `CRON_SECRET`: the same value Render generated
4. Test it: repo → Actions → *Scheduled scan* → **Run workflow** starts a scan right away.

Change the model in the site's **Settings → Model** tab, or with the `OPENROUTER_MODEL` env var. `auto` = newest Claude Sonnet.

### Free-plan notes
- The first page load after a sleep takes about 1 minute.
- GitHub's scheduled runs can start 5–20 minutes late.
- GitHub turns off scheduled workflows after 60 days with no repo activity. The bot's own data commits count as activity, but if the workflow ever stops, re-enable it in the Actions tab.
- A key pasted in the site's Settings only lasts until the service sleeps. Use the Render env var for a permanent key.

## Run locally

```bash
npm install
npm run seed-demo   # optional: 3 fictional findings to preview the UI
npm start           # http://localhost:3000
```

## Cost

Hosting is $0. Each scan makes 5 model calls with web search, twice a day, for about 300 calls a month. You pay for these through OpenRouter, at the price of the model you choose. The web plugin adds a small fee per search.
